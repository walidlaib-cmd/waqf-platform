# منصة 'وقف تاك' (WaqfTech) — المنصة الوقفية الاستثمارية في الجزائر

منصة برمجية متكاملة ومصممة بلغة **بايثون (Python / FastAPI)** لإدارة الأوقاف النقدية واستثمارها وفق أحكام الشريعة الإسلامية ومقتضيات **قانون الأوقاف الجزائري الجديد رقم 25-06** الصادر بتاريخ 23 محرم عام 1447هـ الموافق 19 يوليو 2025م (المنشور في الجريدة الرسمية للجمهورية الجزائرية رقم 47 المؤرخة في 22 يوليو 2025).

## 📋 القرارات التنظيمية المنفذة في المنصة

1. **لكل واقف وقف مستقل:** تم تطبيق بنية حسابات مستقلة لكل واقف (`WaqfFund`) برمز موثق ورصيد منفصل وعقد خاص.
2. **قبول الوقف المؤبد والمؤقت:** إمكانية تخصيص الوقف مؤبداً إلى قيام الساعة، أو مؤقتاً لعدد معين من الشهور مع مصير الأصل.
3. **تمويل مشترك متوازي:** تقبل المنصة تمويل المشاريع من أموال الوقف ومن أموال الممولين الأفراد برؤوس أموالهم الخاصة في آن واحد بحسابات مفصولة.
4. **العملة الأساسية:** الدينار الجزائري (DZD).
5. **أجرة الناظر:** محددة بنسبة **10%** من صافي الأرباح المحققة قابلة للتعديل بقرار رسمي ولا تمس رأس المال.
6. **إلغاء ضمان رأس المال:** التزاماً بالشريعة الإسلامية ومبدأ "الغنم بالغرم"، لا تضمن المنصة ولا صاحب المشروع رأس المال ضد تقلبات السوق الطبيعية.
7. **فترة التراجع (72 ساعة):** مهلة قانونية مدتها 72 ساعة يحق للواقف خلالها سحب كامل المبلغ بضغطة زر وإلغاء الوقف قبل أن يصبح لازماً وناجزاً (المادة 19).
8. **صندوق احتياطي الأوقاف:** استقطاع نسبة معلنة (5%) من الأرباح لتغذية صندوق تكافلي يمتص الصدمات ويخفف المخاطر الاستثمارية (المادة 86).

## 🔄 تنفيذ السيناريو الكامل خطوة بخطوة (المراحل من 1 إلى 13)

### المرحلة الأولى: التسجيل والتحقق من الهوية (KYC/AML)
- **الخطوات 1 - 4:** دخول الموقع، الضغط على "تسجيل جديد"، ملء البيانات (الاسم، الهاتف، البريد، كلمة المرور)، وقراءة الموافقة على الشروط وإفصاح المخاطر.
- **الخطوة 5:** تلقي رمز تحقق (OTP) عبر الهاتف وتفعيله للدخول.
- **الخطوة 6 - 8:** رفع وثيقة الهوية البيومترية والصورة الشخصية (KYC)، المراجعة، وتفعيل الحساب للاستخدام المالي.

### المرحلة الثانية: اختيار نوع الحساب والأدوار المنفصلة
- **الخطوات 9 - 11:** لوحة التحكم تتيح اختيار وتفعيل دور أو أكثر:
  1. **الواقف:** إقرار بمصدر الأموال لمكافحة غسل الأموال (قانون 05-01).
  2. **الممول:** استبيان الملاءمة وتحديد سقف التمويل الأقصى.
  3. **صاحب المشروع:** وثائق السجل التجاري والوضعية الضريبية.
  4. **الجهة المستفيدة:** وثائق الاعتماد والحساب البنكي الجزائري (RIP) والفحص المؤسسي.
  5. **المنصة (الناظر) والهيئة الشرعية المستقلة.**

### المسار الأول: حساب الواقف
- **المرحلة الثالثة (إيداع المبلغ):** الخطوات 12 - 16: إيداع المبلغ الوقفي بالدينار الجزائري (الحد الأدنى 5,000 د.ج)، اختيار وسيلة الدفع (بطاقة CIB، الذهبية، تحويل بنكي)، ظهور المبلغ في رصيد الوقف المستقل.
- **المرحلة الرابعة (شرط الوقف):** الخطوات 17 - 22: اختيار جهة أو أكثر من المجالات الوقفية الثمانية:
  1. وقف على العلم
  2. وقف على الصحة
  3. وقف على البيئة
  4. وقف على رعاية الأسرة والطفولة
  5. وقف على خدمة القرآن والسنة
  6. وقف على اليتامى
  7. وقف لرعاية المساجد
  8. وقف لخدمة المجتمع
  مع تحديد نسب التوزيع (المجموع 100%) والشروط الإضافية (منطقة جغرافية، فئة مستهدفة).
- **المرحلة الخامسة (التعاقد الإلكتروني):** الخطوات 23 - 26: توليد عقد الوقف الإلكتروني الرسمي المتضمن إقرار النظارة، استثمار الأصل دون استهلاكه، توجيه الأرباح للمستحقين، والتوقيع الإلكتروني الرقمي.
- **المرحلة السادسة (المتابعة والإفصاح):** الخطوات 27 - 30: متابعة الأداء، الإشعارات الدورية، وتنزيل شهادة الوقف الرقمية المشفرة.

### المسار الثاني: حساب صاحب المشروع وحساب الممول
- **المرحلة السابعة (طلب التمويل):** الخطوات 31 - 34: تقديم طلب التمويل في القطاعات الخمسة (صناعي، تجاري، زراعي، خدمي، بنية تحتية)، وتحديد المدة والعائد المتوقع والصيغة والضمانات.
- **المرحلة الثامنة (الدراسة والاعتماد):** الخطوات 35 - 39: عناية واجبة فنية ومالية، عرض على الهيئة الشرعية المستقلة، وتصنيف المخاطر (منخفضة، متوسطة، مرتفعة).
- **المرحلة التاسعة (عرض الفرص):** الخطوات 40 - 42: نشر المشاريع في قسم الفرص الاستثمارية مع بيان الصيغ السبع وقواعد تحمل الخسارة.
- **المرحلة العاشرة (الاختيار والاستثمار):** الخطوات 43 - 46: اختيار المشروع، تحديد مبلغ المساهمة، ومراجعة الشروط.
- **المرحلة الحادية عشرة (التعاقد والتنفيذ):** الخطوات 47 - 51: توقيع عقد التمويل الإلكتروني، إيداع المبلغ في حساب الضمان المستقل (Escrow)، والصرف على دفعات مرتبطة بمراحل الإنجاز والمعاينة.
- **المرحلة الثانية عشرة (تحقيق العوائد والتوزيع):** الخطوات 52 - 58:
  1. خصم التكاليف المباشرة المثبتة.
  2. استرجاع أصل رأس المال الوقفي كاملاً لرصيد الوقف المستقل.
  3. توزيع أرباح الممول الفردي وصاحب المشروع وفق الصيغة.
  4. استقطاع 5% لصندوق احتياطي الأوقاف.
  5. استقطاع 10% أجرة ناظر لصالح المنصة.
  6. تحويل الصافي للجهات المستفيدة وفق شرط كل واقف.
- **المرحلة الثالثة عشرة (الشفافية والمتابعة المستمرة):** الخطوات 59 - 63: مؤشرات الأداء الحية، تقارير التدقيق الشرعي الدورية، وقناة الشكاوى والتحكيم.

### 🌟 الطريقة الأولى: نشر المنصة التفاعلية المباشرة عبر GitHub Pages (مجاناً وبدون خادم)

يتضمن المشروع مجلداً خاصاً باسم `docs/` يحتوي على التطبيق التفاعلي المتكامل (`Single-Page Application`). يمكن تفعيله ليصبح متاحاً للجمهور على رابط رسمي مباشر مثل:
`https://<your-username>.github.io/waqf-platform/`

#### خطوات التفعيل بضغطة زر:
1. ارفع المشروع إلى GitHub (راجع خطوات Git أدناه).
2. ادخل إلى صفحة مستودعك على GitHub، ثم اضغط على تبويب **Settings** (الإعدادات).
3. من القائمة الجانبية اليسرى، اختر **Pages**.
4. تحت قسم **Build and deployment**:
   - في خانة **Source**: اختر **Deploy from a branch**.
   - في خانة **Branch**: اختر الفرع الرئيسي (`main` أو `master`)، وبجانبه اختر المجلد: `/docs`.
   - اضغط على **Save**.
5. خلال 60 ثانية، سيظهر لك الرابط الأخضر المباشر:
   `Your site is live at https://<your-username>.github.io/waqf-platform/`

```bash
git push -u origin main
```

### ☁️ الطريقة الثالثة: استضافة الباك إند الكامل (FastAPI + API + Jinja2) مجاناً

لتشغيل خادم بايثون وقاعدة البيانات في السحابة وربطه مع GitHub:

#### 1. النشر على منصة Render (الموصى به - مجاني 100%):
1. سجّل دخولك في [Render.com](https://render.com) بواسطة حسابك على GitHub.
2. اضغط على **New +** ثم اختر **Web Service**.
3. اختر مستودع `waqf-platform`.
4. املأ الإعدادات كالآتي:
   - **Name:** `waqf-platform`
   - **Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn app.main:app --host 0.0.0.0 --port $PORT --app-dir backend`
5. اضغط **Create Web Service**. سيتم إطلاق موقعك خلال دقيقتين مع شهادة SSL مجانية وحماية HTTPS.

#### 2. النشر عبر Docker:
المشروع مجهز مسبقاً بملفات `Dockerfile` و `docker-compose.yml`. للتشغيل على أي خادم VPS:
```bash
docker compose up -d --build
```
